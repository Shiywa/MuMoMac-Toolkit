# Limitations and scope

- Transcriptional features are RNA proxies, not direct functional measurements, protein activity, infectious titers, or clinical diagnoses.
- Provided annotation is the supported default; all-cell automatic macrophage identification is not certified.
- The mouse-derived human extension is experimental. The legacy S BioMart release is missing; the frozen mapping is retained with unknown release provenance, and its redistribution review is pending.
- Targeted spatial panels often have incomplete coverage. Cell-resolved spatial compatibility does not certify cross-modality thresholds. Mixed spots are refused, and neighborhood statistics are not a package feature.
- Original and Expanded use different definitions. They are not an absolute shared scale, and historical mean/q20 thresholds are not transferred to UCell.
- The Seed3 threshold is minimum technical qualification; it does not guarantee biological accuracy and can induce depth/condition selection.
- The four earlier real engineering inputs were already used by the development team and are not independent validation.
- The synthetic example has no biological ground truth. No new biological findings are generated by packaging or CI.
- Unknown animals/donors remain unknown. Cells, sample labels, bootstrap repetitions and model runs do not create biological replication.
- In-memory operation is inherited; backed streaming and million-cell performance are not certified.
- Only the platform and Python/dependency combinations actually listed in the installation audit have been tested. No macOS/Windows success or CI-success claim is made from local Linux tests.
- Code and Reference rights remain pending. This staged candidate is not a public release or a PyPI/Conda/BioConda publication.
