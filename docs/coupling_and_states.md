# Continuous coupling and optional states

The quickstart explicitly uses `representation: {default_mode: continuous_only}`. Continuous scores and within-sample/identity rank associations remain primary. Raw Spearman and technical-covariate-adjusted association answer different descriptive questions; neither is a causal effect or proof of synergy.

C01 uses S03/S05, C03 uses S08/S09, and C04 uses S09/S10 in the example. C02 is an L01/L03 residence-feature pair and requires explicit lifecycle scope; it is not two S functional programs. Default state applicability excludes A01 and does not automatically enable lifecycle states.

The inherited `auto` representation evaluates its frozen distribution/calibration gates. GMM, tail, and relative-high modes require explicit settings and retain their calibration scope and continuous outputs. The wrapper refuses changes to the frozen distribution acceptance criteria. Relative-high is relative to a declared calibration population, not activated versus inactive. No qualified rule means binary fields remain unavailable; invalid values never become Neither.

Sample/identity statistics retain finite-pair counts and qualification reasons. `sample_id` does not establish a biological unit. The main workflow does not generate cell-level disease significance tests, and atlas lookup is only descriptive. The separately inherited state engines are research components; their presence is not general biological certification.
