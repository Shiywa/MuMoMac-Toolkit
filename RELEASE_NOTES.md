# Staged prerelease notes — 0.1.1rc1

This is a local release candidate, not an announcement of a public GitHub Release.

It supports Provided-annotation H5AD input, explicit measurement declarations, Original/Expanded/Both scoring, Original Seed QC and exact detection details, version-separated continuous representations, within-sample/identity program associations, and trusted score-run replay. The core is distributed separately as version 0.3.0 and both packages must be installed.

It does not certify all-cell automatic annotation, functional positivity, cross-study normality, cross-species equivalence, mixed-spot single-cell analysis, disease effects from cell-level replication, spatial neighborhood inference, or million-cell operation. Missing qualification remains NA. No binary policy means Joint/Lift/OR are non-evaluable; A01 remains continuous.

The synthetic example tests implementation only. Existing real engineering inputs were previously exposed. Read the installation audit and test matrix for actual executed checks; CI and public anonymous installation remain unverified until run after authorized repository creation.
