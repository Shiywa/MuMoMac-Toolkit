# Lightweight Reference redistribution scope

Identifier: `LicenseRef-MuMoMac-Reference-Redistribution`.

The author approved public inclusion of the lightweight frozen resources required to run MuMoMac Toolkit on October 18, 2026. This approval covers the project-authored Original/Expanded gene-member definitions, canonical Reference registry and its runtime copies, identity vocabulary/display mapping, and aggregate historical threshold metadata. These resources may be used with and accompany redistribution of the Toolkit with the included source/version notices. No separate standard license for standalone distribution of a Reference database is asserted by this approval.

The canonical registry, gene lists, and numerical definitions remain frozen. Historical thresholds describe a separate legacy representation; they do not calibrate current UCell scores. Aggregate counts in a small frozen metadata table are not an expression matrix or individual animal/patient records.

Third-party mapping entries remain under their upstream terms, including MGI CC BY 4.0, as detailed in `THIRD_PARTY_NOTICES.md`. Derived human mapped-signature JSON files contain project curation plus these mapping facts and retain the same notices. The old Ensembl S-mapping database release remains unknown.

This approval does not include the full Atlas, any real expression matrix or cell subset, raw downloaded research data, individual metadata, or the manuscript. It does not assign those excluded assets an MIT license or authorize their publication.
